System Architecture

The Steamboat data system integrates multiple environmental data streams into a unified, reproducible workflow.

Conceptual workflow and relational structure of the Steamboat geochemical database, illustrating the integration of regulatory, field, laboratory, and sensor data through controlled ingestion pipelines into a normalized relational schema.

This architecture reflects:

  • integration of heterogeneous data sources
  • modular ingestion pipelines
  • a normalized relational database design
  • downstream quality control and modeling workflows

Each component is independently executable but coordinated through a central pipeline.

Data Run

DEMO mode - Database rebuilt from scratch - Deterministic - Used for teaching and reproducibility

OPERATIONAL mode - Database persists - Ingest happens only when explicitly invoked - Protects real field and lab data

Demonstration vs. Operational Databases

For reproducibility and teaching purposes, figures in this document are generated from a demonstration database rebuilt from raw inputs at render time. During active research, the same ingestion pipelines are run incrementally against a persistent operational database, allowing the ingest run log to accumulate and reflect real system evolution through time. In operational mode, ingest‑history visualizations are suppressed until data are ingested, reflecting the true state of the research database prior to field or laboratory uploads.

Script Calls for Data Ingest

# -------------------------------
# SETUP
# -------------------------------
dir.create("database", recursive = TRUE, showWarnings = FALSE)

con <- DBI::dbConnect(RSQLite::SQLite(), DB_PATH)
DBI::dbExecute(con, "PRAGMA foreign_keys = ON;")

# -------------------------------
# CORE INFRASTRUCTURE (ALWAYS ON)
# -------------------------------

# Schema
source("database/schema/01_define_schema.R")

# Helpers
source("scripts/ingest/helpers/parse_datetime.R")
source("scripts/ingest/helpers/update_geometry.R")

# GIS + QC
source("scripts/ingest/create_gis_views.R")
source("scripts/ingest/export_geopackage.R")
source("scripts/qc/validate_database.R")
source("scripts/qc/audit_sample_duplicates.R")

# -------------------------------
# DEMO MODE: FULL RESET
# -------------------------------
if (MODE == "DEMO") {
  
  message("DEMO mode: rebuilding database")
  
  DBI::dbDisconnect(con)
  unlink(DB_PATH)
  
  con <- DBI::dbConnect(RSQLite::SQLite(), DB_PATH)
  DBI::dbExecute(con, "PRAGMA foreign_keys = ON;")
  
  source("database/schema/01_define_schema.R")
}

# -------------------------------
# INGEST PIPELINE (USER CONTROLLED)
# -------------------------------

message("---- Running ingest pipeline ----")

# --- NDEP ---
if (RUN_INGEST$ndep) {
  message("Running NDEP ingest")
  source("scripts/ingest/ingest_ndep.R")
} else {
  message("Skipping NDEP ingest")
}

# --- FIELD ---
if (RUN_INGEST$field) {
  message("Running field ingest")
  source("scripts/ingest/ingest_field.R")
  ingest_field(con)
} else {
  message("Skipping field ingest")
}

# --- TEMPERATURE LOGGERS ---
if (RUN_INGEST$logger) {
  message("Running logger ingest")
  source("scripts/ingest/ingest_temperature_loggers.R")
  ingest_temperature_loggers(con)
} else {
  message("Skipping logger ingest")
}

# --- LAB ---
if (RUN_INGEST$lab) {
  message("Running lab ingest")
  source("scripts/ingest/ingest_lab.R")
  ingest_lab(con)
} else {
  message("Skipping lab ingest")
}

# --- FLUX ---
if (RUN_INGEST$flux) {
  message("Running flux ingest")
  source("scripts/ingest/ingest_flux.R")
  ingest_flux(con)
} else {
  message("Skipping flux ingest")
}

# -------------------------------
# POST-PROCESSING (ALWAYS RUN)
# -------------------------------

message("---- Running post-processing ----")

# Geometry (safe to rerun)
update_location_geometry(con)

# GIS Outputs
create_gis_views(con)
export_geopackage(con)

# QC Validation
validate_database(con)
audit_sample_duplicates(con)

message("✅ Pipeline complete")
